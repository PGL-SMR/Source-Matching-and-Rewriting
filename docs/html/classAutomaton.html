Detailed Description

Base implementation of a finite state automaton.

This class is used to create and traverse a finite state automaton. It implements base functionalities such as adding states and transitions, as well as traversing the automaton.

◆ add()

int Automaton::add ( const std::vector< int > &  Transitions)

Inserts a path in the automaton.

Given a list of transitions, it will try to traverse the automaton from the starting state.

If at some point it fails to transition to the next state, it creates a new state to satisfy the transition.

The final in the traversal will be marked as final.
